# DermaCare

PWA مخصّص للموبايل لمركز علاج البشرة والليزر: حجز مواعيد، رسائل من المركز، بطاقة زيارات، تذكيرات، وربط بالتقويم. بالإضافة للوحة إدارة بتشتغل من الموبايل.

## التشغيل

```bash
npm install
npm run dev
```

إذا ما في متغيرات Supabase، التطبيق بيشتغل **بالوضع التجريبي** والبيانات بتنحفظ بالمتصفح:
- رمز الدخول للزبونة: `1234`
- لوحة الإدارة: `/admin`، أي بريد إلكتروني، وكلمة المرور `admin`

## التشغيل الحقيقي (Supabase)

1. افتح مشروع Supabase، ونفّذ الملف `supabase/migrations/001_init.sql`.
2. **Auth → Phone:** فعّل تسجيل الدخول بالهاتف، واربط مزوّد SMS (Twilio أو MessageBird أو Vonage).
3. **Auth → Users:** أنشئ مستخدم بريد وكلمة مرور لصاحب المركز، وبعدها نفّذ:
   `insert into admins (user_id) select id from auth.users where email = '...';`
4. انسخ `.env.example` إلى `.env` واكتب فيه `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY`.
5. Edge Functions:
   - `supabase functions deploy calendar-feed --no-verify-jwt`: رابط تقويم الإدارة (Google/Apple).
   - `supabase functions deploy send-reminders`: لازم تضيف `VAPID_PUBLIC_KEY` و`VAPID_PRIVATE_KEY` و`VAPID_SUBJECT`، وتجدول الدالة تشتغل كل 15 دقيقة.
6. الاستضافة: Vercel أو Netlify. ملفات إعادة توجيه الـ SPA (`vercel.json` و`public/_redirects`) موجودة.

## المزايا

- **الزبونة:** تسجيل مرة وحدة برمز SMS، حجز بثلاث خطوات، عداد تنازلي للموعد القادم، إضافة الموعد لـ Google أو Apple، زر دفع مسبق ببيت، اتصال وواتساب، رسائل المركز، بطاقة زيارات، تذكير push، وتثبيت على الشاشة الرئيسية.
- **الإدارة:** جدول يومي (تمّ، لم تحضر، إلغاء، تسجيل دفع، تذكير جاهز بالواتساب)، إضافة موعد يدوي، قائمة زبائن مع فلاتر (الزيارة القادمة هدية، أكملت الدورة، ما زارت من شهرين)، رسائل عامة أو خاصة، تشغيل وإيقاف بطاقة الولاء وتحديد عدد زياراتها، ساعات العمل، العلاجات، ورابط تقويم بيتحدّث لحاله.
- **قاعدة البيانات:** بتمنع حجز موعدين بنفس الوقت (exclusion constraint)، وفي صلاحيات RLS، فكل زبونة بتشوف بياناتها بس.
